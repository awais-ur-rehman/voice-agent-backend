# Phase 0 CPU tooling implementation plan

**Goal:** Prepare a repeatable, synthetic hosted-LLM evaluation without a GPU or credentials in Git.

**Spec:** `docs/superpowers/specs/2026-10-27-phase-0-cpu-design.md`, based on the owner's v0.1/v0.2 specs.

**Architecture:** Separate streaming HTTP transport, fixed fixture suite, deterministic scoring, and CLI/report orchestration. Use the standard library for the experimental runner; production adapters remain future work.

## Constraints and review focus

Use Python 3.12; never expose the key; do not follow redirects; validate endpoints; do not count role-only deltas as tokens; incomplete streams cannot succeed; tool schema validity and expected-value correctness are separate; Urdu script presence does not prove naturalness. Full GPU feasibility remains pending.
