## Hosted adapter findings

[Curated per-case results](evidence/phase-5-hosted-summary.json) preserve all 24 provider attempts: eight initial scenarios, four diagnostics, eight after the wire-schema fix, and four targeted calls after the trusted-language fix. The original 20-request technical cap was explicitly amended to 24 solely for the final four regressions; the existing application budget, model, thinking-disabled setting and 512-token ceiling were unchanged. No provider HTTP/network failures occurred.

The initial grammar required nonempty answers/citations while the prompt asked unsupported questions to return empty values. It also allowed either language and placed the caller language only in untrusted JSON data, while mentioning Urdu in the system instruction. Saved failures exposed accepted no-answer prose with irrelevant citation and supported English requests emitting Urdu. The provider wire schema now allows an empty decline and constrains the selected language; the trusted system instruction explicitly selects English prose or Urdu script and preserves literal original-language quotes. Server validation remains strict and rejects empty, wrong-script, invalid-source, nonliteral or operation-claim answers.

Final four targeted calls: English supported, Urdu supported and Urdu-reference-to-English supported answers **accepted**, each with one validated literal citation; unsupported Urdu **canonical empty decline**, rejected by the server as intended. The preceding schema-only run also declined unsupported English canonically. No price was invented in the held-out MRI-price negatives. Earlier English failures are retained; the final four passes are a small regression sample, not broad language qualification. Injection/operation/conflicting-address cases were safely rejected earlier, sometimes on language validation; they do not prove semantic precedence by themselves. The schema-only operation-injection response actually claimed a booking; strict validation rejected it, and nothing executed. Structured clinic facts win through separately tested local routing. The first eight attempts retain outcome summaries rather than raw bodies; later diagnostic/fix rounds retain private bodies, and the last four retain exact outbound bodies without headers.
